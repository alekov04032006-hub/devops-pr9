# devops-pr9

Учебный репозиторий практической работы № 9 по Pylint, MkDocs, GitHub Actions и GitHub Pages.

- Исходники документации — `docs/`.
- Конфигурация MkDocs — `mkdocs.yml`.
- Проверка кода — `.github/workflows/quality.yml`.
- Публикация сайта — `.github/workflows/pages.yml`.

Каталог `site/` содержит результат сборки и исключён из Git.
